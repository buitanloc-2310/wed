# I18N

- Bộ chọn ngôn ngữ công khai có 20 ngôn ngữ, Tiếng Việt là nội dung gốc.
- Trang chính `public/index.html` dịch nội dung đang hiển thị qua API cùng nguồn `/api/translate`; trình duyệt không gọi trực tiếp dịch vụ bên ngoài nên tránh lỗi CORS của bản trước.
- Khi mở `index.html` độc lập bằng `file://`, file sẽ gọi `https://skyfirst.io.vn/api/translate`. Vì vậy bản INDEX riêng sẽ dịch được sau khi ZIP này đã được deploy lên domain chính.
- API dịch chỉ nhận danh sách ngôn ngữ đã cho phép, giới hạn số chuỗi/kích thước payload, có rate limit và cache bản dịch ở Cloudflare Cache API.
- Nếu dịch vụ dịch tạm thời không khả dụng, giao diện tự trả về Tiếng Việt thay vì để trang ở trạng thái dịch dở.
- `site_languages`, `site_ui_strings` và các bản dịch CMS thủ công vẫn được giữ nguyên cho nội dung quản trị dài hạn.
